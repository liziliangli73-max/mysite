# iPhone 17 · 3D 拆解实验室

一个仅依赖 **Three.js + HTML + CSS + JavaScript** 的交互式 iPhone 17 三维拆解页面。所有手机几何体、屏幕界面、电路纹理、相机镜片、MagSafe 结构和标注都由代码实时生成，不使用任何外部 3D 模型或贴图文件。

## 打开方式

直接双击 `index.html` 即可运行。Three.js 已放在 `vendor/three.min.js`，无需联网。

如果浏览器限制本地文件运行，也可以在当前目录启动一个静态服务器：

```bash
cd iphone17
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 交互

- **拖动**：旋转机身视角
- **滚轮 / 双指捏合**：缩放
- **点击部件 / 左侧清单**：拆解并高亮对应部件，右侧显示参数
- **一键拆解 / 空格**：展开或合拢全部结构
- **背面视角**：在机身正面与背面之间切换
- **自动旋转**：开启缓慢环绕展示
- **标注**：显示 / 隐藏三维部件标注
- **操作指南**：查看完整操作说明
- **R**：复位；**L**：标注开关；**Esc**：关闭面板

## 主要实现

- 程序化圆角几何体构建铝合金中框、超瓷晶面板、双摄模组与内部结构
- Canvas 实时绘制锁屏界面、A19 芯片丝印、电池标签、PCB 走线与法规丝印
- 射线拾取实现部件点击，阻尼弹簧驱动拆解动画
- 自定义轨道相机支持旋转、缩放、双指手势与视角预设
- 自发光描边、辉光 Sprite、局部点光源构成选中高亮
- 响应式布局：桌面双面板 HUD，移动端底部抽屉式清单 / 参数面板
